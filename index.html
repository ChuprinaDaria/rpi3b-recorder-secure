Pi 3B secure REC · LAN

Периметр знищено — усі LUKS-контейнери у /opt/opsec/ затерто: rec.img (відео) + cv.img (cv-tracking + venv). Keyslot-и стерто (cryptsetup luksErase), header затерто (dd urandom 16M). Дані на носії лишаються випадковим шумом — без ключа декрипт математично неможливий.

Стан LUKS-контейнерів

◌ LUKS: —
Контейнер Файл Стан Розмір
🔓 mounted
Ключ у RAM. Файли пишуться зашифрованими на диск, але дешифруються при читанні. Все, що робить ffmpeg, потрапляє у контейнер.
🔒 unmounted
Ключ вивантажено з RAM. Дані на диску, але без пасфрази прочитати не можна. Keyslot-и ще на місці — можна знову відкрити.
✖ destroyed
Обидва контейнери (rec.img + cv.img) втратили keyslot-и і header. Файли існують як випадковий шум. Ключ математично неможливо відновити.
